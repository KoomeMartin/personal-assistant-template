# Tailor resume

1. Read the job description (from the message, `inbox/` or `vault/opportunities/`). Save it as an `opportunity` note if it isn't one already, with its deadline in `calendar.md`.
2. Extract: must-have requirements, nice-to-haves, key words, and what the organisation seems to value.
3. Read `me/cv.md`, then search `vault/projects/` and `vault/courses/` for evidence matching each requirement. Projects in the vault often hold detail missing from the CV — use it.
4. Make a match table: requirement → best evidence → source note. Mark gaps honestly.
5. Write a one-page CV in markdown to `me/applications/<organisation>-<role>.md`: reorder and reword to fit the role, lead with the strongest matching evidence, mirror the posting's key words where they are true. **Never invent experience, dates, grades or skills.**
6. Draft a short cover letter (under 300 words) in the same folder.
7. Reply with the match table, the gaps, and the files' paths. End with: "Check every line is true before you send it."
