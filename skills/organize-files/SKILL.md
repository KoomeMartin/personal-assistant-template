# Organize files

1. Ask which folder, if not given. It must be inside this workspace.
2. List every file. Open each one that has a meaningless name (`IMG_…`, `Document1`, `scan0003`, `final_final(2)`) and work out what it is.
3. **Propose before acting.** Show a table: current name → new name → destination folder → reason. Folders follow the person's courses and projects from `vault/` (e.g. `courses/data-structures/`, `projects/capstone/`, `admin/`, `opportunities/`). New names: lowercase, hyphenated, with a date if relevant (`2026-11-07-assignment-3-brief.md`).
4. Wait for the person to approve or edit the plan.
5. Move and rename exactly as approved. Never delete; duplicates go to `archive/duplicates/`.
6. Log every move in `logs/actions.md`. If a file contains deadlines, events or opportunities, offer to run the `ingest` skill on it.
