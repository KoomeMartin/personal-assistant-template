# Weekly review

1. Read this week's files in `digests/daily/`, `todos.md`, `calendar.md`, `me/goals.md`, and notes in `vault/` changed this week (check `logs/actions.md`).
2. Write `digests/weekly/YYYY-Www.md` with:
   - **Done this week**
   - **Slipped** — and the pattern if there is one (same course, same day, same kind of task)
   - **Next week** — every deadline and event, then a suggested top 5
   - **Goals** — progress toward each goal in `me/goals.md`, honestly
   - **New in your knowledge base** — people, ideas and opportunities captured this week, with links
   - **One question** for the person to reflect on
3. Send a `notify` push: title "Your weekly review is ready", message = next week's 2 most important deadlines.
